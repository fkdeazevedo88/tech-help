# DIY Fix Line website

The public website for a home-based video-call help line: guiding homeowners and businesses
through DIY HVAC, plumbing, electrical, appliance and walk-in freezer fixes across Canada.
It's one file, `index.html`, served free by GitHub Pages.

To change the name, phone number, email, prices or booking link, edit `index.html` (search for
`DIY Fix Line`, `(000) 000-0000`, `help@example.com` and `calendar.google.com`).
